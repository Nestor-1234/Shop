# Мелодія

Базовий адаптивний інтернет-магазин музичних інструментів на HTML, CSS і JavaScript без додаткових залежностей.

## Запуск

Каталог завантажується з `store_db.json`, тому сторінки потрібно відкрити через локальний вебсервер, а не напряму як `file://`.

Наприклад, якщо встановлено Python:

```powershell
py -m http.server 8000
```

Потім відкрийте <http://localhost:8000>.

## Можливості

- Каталог інструментів із пошуком, фільтром категорій і сортуванням.
- Кошик із кількістю товарів, підрахунком суми та збереженням у `localStorage`.
- Демонстраційне оформлення замовлення без платежів і серверної обробки.

Товари редагуються у `store_db.json`.
